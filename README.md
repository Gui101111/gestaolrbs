# Viking Praia · Steak & Beer

Site one-page do Viking Praia, bar de praia na Praia do Parracho, Arraial d’Ajuda (BA).

HTML, CSS e JavaScript puros, sem build: abra com qualquer servidor estático.

```
python3 -m http.server 8000
# http://localhost:8000
```

- `index.html`: página
- `assets/css/style.css`: visual (mobile-first)
- `assets/js/main.js`: motor de movimento (ondas, fio do mar, escudo, parallax, reveals)
- `assets/img`: fotos em AVIF/WebP
- `assets/video`: vídeos sem áudio em MP4 (H.264) e WebM (VP9)

Antes de publicar: troque `https://vikingpraia.com.br/` pelo domínio final nas tags marcadas com `DEPLOY STEP` no `index.html`.
